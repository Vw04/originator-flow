Design Rationale

What changed from current:
  • Eliminated 11-tab left sidebar → 5 content tabs (Overview, Tasks, Documents, Parties, History)
  • Horizontal stage tracker replaces both the 9-step stepper (Applications) and the accordion pipeline (Originations)
  • Right sidebar for at-a-glance panels (Next Actions, Warnings, Key Dates, Parties) — always visible while scrolling content
  • Context header with key loan chips — no need to hunt for FICO, LTV, program info
  • Color-coded owner badges — instantly see who owns each task (LO = purple, AM = blue, Borrower = amber, System = gray)
Consistency between Applications & Originations:
  • Same layout structure for both views
  • Same stage tracker (Applications maps its 9 steps into the same 6 stages)
  • Same content tabs and sidebar panels
  • Same owner badge colors and task row patterns
  • Originations detail = full pipeline with all 6 stages
  • Applications detail = same view, with step-specific content highlighted in the active stage
For someone new to originations:
  • The stage tracker tells you exactly where this loan is in the process at a glance
  • "Next Actions" panel immediately shows what needs to happen and who should do it
  • Warnings panel flags problems proactively (stalled, missing dates, expiring locks)
  • Owner badges answer "whose turn is it?" without needing to understand the full workflow
  • Overview tab shows current stage tasks + loan summary — the most common view — without any navigation clicks
