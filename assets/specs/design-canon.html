05

Action bars

Sticky top "Back to X" + sticky bottom Save/Submit/Next. Together they frame editable pages and keep primary actions reachable without scrolling.

‹ Back to Branches
Form content scrolls here. Title, section cards, fields. Both bars remain stuck.
Unsaved changes

Scope rule

The sticky-bottom action bar appears only on form/wizard pages and the edit sub-routes of hybrid pages. List-only views (rosters, dashboards) do not get the bar — there's nothing to save. See the rollout table below.

Dirty state

On entering edit mode, the body class is-dirty is unset and the indicator reads "No changes" in muted gray. The first input event in the form bubbles up to a delegated handler that adds is-dirty, flipping the dot + label to brick-red ("Unsaved changes"). Save and Cancel both clear the flag.

07

What we kept

Tokens and patterns deliberately NOT migrated. These represent areas where we lead the dev team, or where our existing implementation is non-negotiable.

92px left sidenav

The Figma file uses a top horizontal nav. We keep the fixed 92px icon rail (with logo, tile, divider, profile stack, flyouts). This is our direction; subsequent Figma iterations should adopt ours.

IvyPresto Display 300

Figma frames use Georgia as a stand-in (no license required). We hold the IvyPresto license, so page titles use the premium serif. Both render at 28px / 33.6 lh / --color-primary.

Semantic status colors

The Figma frames inspected don't include success / warning / info semantics. We keep our existing palette: #16a34a / #d97706 / #2563eb.

RBAC + permissions UI

The permission matrix and platform-operator RBAC patterns (platform-rbac.js) are ours alone. They inherit warm tokens; the screen layouts remain.

Institutional artboard tokens

css/institutional.css (the --h-* token set) is untouched. The 8 directional mockups in Loan Origination v2.html consume it and represent exploratory work the canon does not constrain.
