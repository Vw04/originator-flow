01 · Open conflicts

Decisions locked in Phase 3 that the kit overrides

These two items were explicitly locked during your Phase 3 sign-off and have already shipped to css/styles.css and js/views/branches.js. The brand kit contradicts both. Resolve these first.

Primary CTA color

Critical locked in 05ab465 · btn-primary

What we shipped

Navy --color-primary: #00334a drives .btn-primary across every view. The same token does double duty as the brand anchor for page titles and the sidenav active state.

What the kit says

Green-500 #14935F is the **Primary CTA / M3 Primary**. Navy is the brand anchor (logo, headings, nav) and the action color in dark mode is gold — but in light mode, green is the only color that signals "click me."

Recommendation · Adopt kit Introduce --color-cta: #14935F and rewire .btn-primary to use it. Keep --color-primary = navy for headings + nav + brand anchor. Pair with the kit's hover/active scale: green-700 #117A4A (hover), green-900 #0D6B40 (pressed). Note: kit's success status uses a different green (#1A8754) — don't conflate the two.

Navigation architecture

Critical locked in design-canon.html · "What we kept"

What we shipped

Fixed 92px left icon rail with the existing sidenav (logo, tile icons + labels, profile stack, flyouts). Our canon doc explicitly says: "We keep ours — we lead here. Figma uses top nav."

What the kit says

Two-layer top NavBar (full-width teal-900, 56px) with logo + nav items + user dropdown. Side nav only for detail pages (220px white card, sticky at top: 80px). Mobile collapses to hamburger + centered logo.

Homium Dashboard Originations Setup
Recommendation · Negotiate This is a substantive UX architecture call — bring the left-rail prototype to the dev team before flipping. Our rail is icon-only (92px); the kit's top-nav is text-label (56px). They're different mental models. If the platform is a multi-role institutional tool with deep sections, the left rail wins on hierarchy; if it's a 5–7 top-level destination tool, the top nav wins on horizontal real-estate. The kit's spec is detailed (active green underline, dropdown groups, user area on right) — they've thought it through. Bring data on use-cases, then decide.

05 · New concepts from the kit

Things we didn't have, that the kit declares canonical

These are additive — not in conflict with anything we shipped. Recommendation on each is when to adopt.

Data viz palette

Sequential teal ramp, categorical 6-color (navy, green, teal, purple, gold, teal-2), diverging red→green pair (only place red/green appear in charts). Opacity stepping --step-1…5 for single-variable bars.

Adopt when we build the first chart. Don't reinvent.

Chart tooltip pattern

White bg, 1px stone border on all sides, 3px green-500 top accent (direction-independent — never left/right). Two-line content: Inter 11px label + Georgia 18px value. JS-positioned, never CSS pseudo-element.

Adopt with the first chart.

Dim-siblings hover

On chart bar hover: container gets .is-hovering, bar gets .is-hovered. All bars dim to opacity 0.40, hovered bar to 0.85. Never filter: brightness().

Adopt with first chart.

Tabler Icons (1.5px stroke)

Standard icon library — 5,700+ line icons. 20px standalone, 16px inside components. Stroke always 1.5 to match border weights. Never mix libraries.

Adopt immediately. Audit existing inline SVGs.

Spacing scale tokens

--h-space-2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64. Every padding, margin, gap. No arbitrary pixel values.

Adopt in :root; migrate ad-hoc spacing over time.

Shape vocabulary

4px squares (chart bars, code blocks), 6px controls (buttons, chips, inputs), 8px cards, 12px modals, 50% circles (avatars, dots), 999px pills (badges).

Adopt as the audit lens — check each component's radius against this scale.

Surface hierarchy

Page #F9F8F4 → card white → nested expanded sand #F2F0EA → inner card white → table zebra #FAFAF8. Pearl #F8F7F4 reserved for readonly inputs.

Adopt incrementally as views are refactored.

Dark mode (complete spec)

Page #071620, action color flips from green to gold #D4A017, dark-green-cta brightens to #1EAA6E, semantic colors all softened.

Defer. Phase 3 explicitly out-of-scoped dark; capture in canon doc for the future.

Compact density rule

Default: 36px table rows / 32px inputs / 28px chips. Comfortable toggle available for users who prefer M3 default density.

Adopt — partial overlap with input height delta above.

07 · Resolution legend

Vocabulary for per-row decisions

Use this when you reply with your per-row calls — the same four verbs the recommendations use.

Adopt kit

Update our canon to match the brand kit value verbatim. Most common for token-level deltas where the kit is more thought-through.

Keep ours

Our value stands. The kit is wrong, or the delta is a deliberate platform choice we'd lose by matching.

Negotiate

Bring it to the dev team. The choice has trade-offs and needs alignment before either side moves.

Defer

Note and capture, but don't change yet. Common for additive concepts we haven't built (charts, dark mode).
